# NexTab Engine v3.2.0 – Ultra Clean

Lokaler Build wurde erstellt und die JavaScript-Syntax sowie die ZIP-Integrität geprüft. Die ZIP-Datei **NexTab-Engine-v3.2.0.zip** muss noch als GitHub-Release mit dem Tag **v3.2.0** hochgeladen werden. Die GitHub-Verbindung bietet hier keine Release-Asset-Uploadfunktion.

## Enthaltene Verbesserungen
- **1 Ultra Glass UI:** dezenter Glas-Look für Suche, Einstellungen und Schnellzugriffe.
- **3 Smart Snap:** Uhr, Suchleiste und Icon-Gruppe rasten beim Verschieben nahe der Fenster-Mitte ein (deaktivierbar).
- **5 Smooth Transitions:** weiche Überblendung beim Wechsel des Wallpapermediums, berücksichtigt reduzierte Bewegung.
- **12 Performance Mode:** schaltbare Reduktion von Unschärfe, Schatten und dekorativen Animationen; Videos werden weiterhin bei unsichtbarem Tab pausiert.
- **13 Invisible Edit Mode:** Griffe werden außerhalb des Bearbeitungsmodus nicht gezeigt.
- **14 Responsive Design:** verbesserte Darstellung auf kleineren Fensterbreiten.

Alle bisherigen Live-Wallpaper, Videos, Einstellungen, verschiebbaren Widgets, die Windows-Bridge und der 10-Minuten-Updater bleiben im Paket enthalten.

## Veröffentlichung
1. Das ZIP **NexTab-Engine-v3.2.0.zip** herunterladen.
2. https://github.com/nxn7gmcgmt-byte/NexTab-Erweiterung-Browser/releases/new öffnen.
3. Tag `v3.2.0`, Titel `NexTab Engine v3.2.0 – Ultra Clean` eingeben, ZIP unter **Attach binaries** anhängen und veröffentlichen.
4. Der bereits installierte Windows-Updater entdeckt das öffentliche Release bei der nächsten 10-Minuten-Prüfung. Brave danach neu starten.
