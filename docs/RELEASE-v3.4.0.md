# NexTab Engine v3.4.0 – Cinematic Clean

Erweiterung lokal als `NexTab-Engine-v3.4.0.zip` gebaut. Das Archiv wurde geprüft und `node --check newtab.js` bestanden.

Neu: Alle NexTab-Elemente mit einem Klick ausblendbar; dauerhafter dezent sichtbarer Schalter rechts sowie Tastenkürzel `Alt+H`; Uhr/Datum, Suche und Webseiten-Icons einzeln ein- oder ausblenden; überarbeitete Sichtbarkeitseinstellungen mit Schaltern; transparenteres, ruhigeres Einstellungsdesign. Alle vorherigen Wallpaper, lokalen Windows-Bridge-Funktionen und das GitHub-Updatesystem bleiben im Paket.

**Wichtig:** Eine Erweiterung darf die Adressleiste, Tabs oder Symbolleiste von Brave nicht verändern. Für echten Vollbildmodus `F11` verwenden. `.pkg`-Szenen erhalten in dieser Version **keinen echten Live-Capture**; das würde eine zusätzliche Windows-Capture-Komponente mit Bildschirm- oder Fensterfreigabe erfordern. Der Status wird nicht als implementiert ausgegeben.

## Release veröffentlichen
Tag `v3.4.0`, Asset `NexTab-Engine-v3.4.0.zip` (mit `manifest.json` direkt im ZIP-Stamm), als öffentliches GitHub Release veröffentlichen. Nur so erkennt der Windows-Updater die Version. Der Browser muss nach der lokalen Installation neu gestartet werden. Live-Test unter Brave noch ausstehend.
